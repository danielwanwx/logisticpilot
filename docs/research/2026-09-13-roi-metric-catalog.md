# LogisticPilot：64 项业务与 Agent 指标目录

截至 2026-09-13 UTC。配套 [商业价值研究](2026-09-13-distributor-agent-roi-research.md) 与 [代码／数据可行性盘点](2026-09-13-roi-data-feasibility.md)。本表是指标需求定义，不是已经接通的 dashboard，也不是已有客户数据集。

## 使用约定

- **C**：当前分销路径已有相关字段或事件。仅代表输入支持，未必已有指标计算／展示；确切的租户记录见可行性盘点。
- **L**：旧路径有部分字段／计算，当前 `/operations` 未接通完整指标。
- **N**：需要新增读取、关联、埋点或数据；ERP 有对应功能不等于当前租户有记录。
- **X**：当前项目的数据不足以推导；需要另一类业务系统或真实观察。
- `Σ` 为已声明窗口和范围内求和；比例分母为零、缺失或不完整时返回不可计算。币种、UOM 和税口径必须一致。所有率同时展示分子、分母和窗口，不只展示百分比。
- 以下是为本产品明确的操作口径，不声称每一项都是行业唯一标准。事件量、成本和金额不得跨阶段重复累加。阈值由用户业务规则或可比历史确定，不能把外部案例数值直接变成默认目标。

## A. 质量与受限库存（负责人：收货／质量）

质量成本分类参考 [ASQ](https://asq.org/quality-resources/cost-of-quality)，抽样比例定义参考 [NIST](https://www.itl.nist.gov/div898/handbook/pmc/section3/pmc332.htm)。口径需要落实到批次及检验方法。

| ID | 指标与公式 | 粒度／需要的数据 | 当前 | 可触发的有用动作／主要误用 |
| --- | --- | --- | --- | --- |
| M01 | 首检失败批次频率＝首检失败的唯一批次／完成首检的唯一批次 | 供应商×物料×规格版本×方法×窗口；QI、PR、PO、batch，首次／复检标记 | N；仅单案 QI 已验证 | 启动供应商 QA 调查；复检不能稀释首次失败，不同批次不自动独立 |
| M02 | 抽样不合格品比例＝实际不合格样本件数／实际受检件数；可另按百万件表达 | 每个实际受检件的结果、sample_size、样本选择方式 | X | 解释抽样风险；QI 状态失败不提供失败件数，隔离数不是不良数 |
| M03 | 隔离数量＝有效入隔离数量－有效放行／退货／报废数量 | 批次×仓库×时点；PR、Stock Entry、库存状态及取消记录 | C | 识别受影响范围；不能当企业全部库存或缺陷数量 |
| M04 | 隔离占比＝同一收货群组当前仍隔离数量／该群组净接收数量 | 明确收货群组、截止时点和退货；M03、PR | L/N | 对比同类接收压力；不能将某时点余额除以不相关期间流量 |
| M05 | 隔离时长＝有效处置时间－进入隔离时间；未结案显示当前 age | 批次隔离区间，来源事件时间及记录时间 | N | 催办超时处置；未关闭案件不能从统计中删掉，报告中位数与 p90 |
| M06 | 复检周转时间＝复检结果时间－复检请求时间 | 复检任务、QI、授权及取消状态 | N | 安排检测资源；不能据此跳过必要检测 |
| M07 | 出库后质量问题率＝确认质量问题的出库行／到达观察期限的出库行 | DN、客户投诉／退货、lot，固定成熟窗口 | X | 调查质量外流；近期出库尚无投诉不等于通过观察 |
| M08 | 质量失败成本＝关联事件的报废、返工、分拣及外部失败实际成本之和 | 唯一 cost_line、工时、费用发票、库存估值；区分预防／鉴定 | N | 找高成本事件和可追偿项；不得把正常检验全部计入失败成本，也不得重复记原料损失 |

## C. 履约与客户承诺（负责人：运营／客户服务）

对照定义可参考 [APQC perfect order](https://www.apqc.org/resources/benchmarking/open-standards-benchmarking/measures/perfect-order-performance)。本表 M22 使用订单级联合通过率，不假设它等同于其他机构使用的子比例乘积指标。

| ID | 指标与公式 | 粒度／需要的数据 | 当前 | 可触发的有用动作／主要误用 |
| --- | --- | --- | --- | --- |
| M17 | 合同及质量允许发货数量＝确定性约束下的可行分配数量 | SO 子行、客户规则、批次放行、库存、现有预留、规则版本 | C | 准备可批准方案；可行不代表最低成本，更不代表已发出 |
| M18 | 剩余履约义务＝当前有效应履约量－已履行量；包含批准的补发义务，最低为零 | SO 子行、DN、客户批准的取消、退款结案或换货／补发处置 | C/N | 当前仅支持原案例未发量；退货不自动产生补发义务，退款结案不能重新算欠货 |
| M19 | 首次单位发货满足率＝固定截止时点已履行原始义务数量／同群组原始应发数量 | 到期订单群组、DN、UOM；取消的纳入规则预先冻结 | C/N | 后续退货不回改这项首次履约指标；补发单列，质量外流见 M07，净库存流量见 M25 |
| M20 | 首次订单行完全发货率＝截止时点足量履行原始义务的行／全部纳入的到期行 | SO、DN 子行及截止日期；同 M19 的固定取消规则 | N | 一行分多次发货只计一行；退款／补发义务另见 M18，不用负数退货单机械倒扣 |
| M21 | OTIF＝在客户约定窗口内足量实际交付的订单／全部到期订单 | SO 承诺、POD／客户接收、数量及迟到／未知结果 | X | 管理服务承诺；DN 和合成 carrier event 不能证明真实交付 |
| M22 | 完美订单联合通过率＝按时、完整、无损、单据准确同时满足的订单／成熟订单群组 | M21、损坏／退货观察、账单与单据核查 | X | 找失效维度；缺任一维度显示未知，不以其余维度补满 |
| M23 | 决策至核验发货耗时＝原系统读回确认时间－任务决策开始时间 | 单调计时、审批、DN submit 与 readback；另报审批等待 | N；已有部分事件 | 定位操作瓶颈；本地 recorded_at 不是全部业务发生时间 |
| M24 | 客户承诺修订率＝有批准交期／数量改约的订单／窗口内开放订单 | 原始及修订承诺、客户批准、原因 | N | 主动协商可行替代；不能靠不断改交期制造高 OTD |

| M55 | 超时未结案占比＝截至时点超过适用处理期限的开放案件／开放案件 | 业务 SLA、优先级、冻结／暂停原因、当前状态 | N | 排序待办；临时改 deadline 不能抹除历史超时 |
| M56 | 每正确结案全成本＝所有尝试的人工＋技术＋合理分摊成本／正确结案数 | 所有成功失败尝试、审核、维护、成本政策 | N | 比较规则、单 Agent、多 Agent；失败调用和返工必须进入成本 |

## 采集与验证次序

| 数据组 | 首选读取／采集方式 | 更新边界 | 完整性与验收 |
| --- | --- | --- | --- |
| 当前库存、质量、订单和可行方案 | 只读 ERP 原生单据与子行；决策前读取，执行后再次读取 | 显示每个来源时点；变化后旧方案失效 | 精确 case／line／lot 关联；取消、退货、重复操作纳入 |
| 历史质量／交期 | 分页拉取明确日期范围的 PO、PR、QI、修订记录 | 增量更新并检测回填；群组定义版本化 | 与源系统群组总数核对；保留缺失、排除及复检身份 |
| 合同、费用、报价 | 授权范围内原始文件／邮件／系统记录；人工确认抽取结果 | 有效期、适用对象、替代版本明确 | 每项成本可定位到条款或凭证；报价过期须重取 |
| 索赔、贷项、收付款 | 申请记录、对方回执、AP、GL／Payment Ledger 对账 | 按业务结算更新；撤销和冲正可追溯 | 申请、接受、记账、结算分状态；唯一损失避免重复 |
| 人工与 Agent 过程 | 明确开始／结束／重做的任务事件、使用量记录；配对人工观察 | 每次尝试都记录，包括失败 | 校对计时，脱敏；不记录密码、会话凭据或无关个人数据 |

这些是未来采集要求；本研究没有为了填满指标表而生成租户历史、运行新的 ERP 写入、创建索赔或声称观察到人工节省。

第一轮验收宜集中 M17、M18、M23、M36、M42、M49、M56、M57。它们连接现有履约链与新增方案经济比较，能回答“是否正确、是否更省事、方案是否更合算”。M37–M41 是后续完整追偿流程；M01、M15、M64 需要完整历史。其余作为需求与数据路线，不全挤进首屏。
