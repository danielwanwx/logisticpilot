# Photo review label fixtures

These are synthetic POC label documents for the photo-review browser demo. They are flat rendered labels generated by [`generate_labels.py`](generate_labels.py), not camera photos.

The documents contain only declared text fields:

- `input-01.png`: `ITEM: M20-DIST-COMPONENT-NOS`, `LOT: LOT-B5`, `QTY: 5`
- `input-02.png`: `ITEM: M20-DIST-COMPONENT-NOS`, `LOT: LOT-X9`, `QTY: 5`

The `QTY` field is a declared label value only. These fixtures make no photo-accuracy, OCR, inventory, quality, defect, pass/fail, or expected-answer claim. The visible `SYNTHETIC POC LABEL` watermark identifies their demo provenance.

[Bolzenbruch.jpg](https://commons.wikimedia.org/wiki/File:Bolzenbruch.jpg), by
[Ulfbastel](https://commons.wikimedia.org/wiki/User:Ulfbastel), dated August 1,
2007. The author released it into the public domain worldwide. The original is
[available here](https://upload.wikimedia.org/wikipedia/commons/0/0c/Bolzenbruch.jpg).
SHA-256: `3401672749ec6b861bf5a08788b8c7a66e102fbdeb4d5bd3012bf133483056d6`.

It depicts a broken bolt and adjacent nut, including a cropped outer edge and
a scale. It is not our receiving dock, not the contents of the earlier public
carton photograph, and not evidence of our demo item's dimensions. Any demo ERP
association is explicitly synthetic. Only the original image pixels and the
requested inspection purpose reach the reader; the source title and expected
observations remain outside model input. Use this to test local-detail review,
not to claim calibrated measurements, exact inventory counts, or industrial
quality certification.
