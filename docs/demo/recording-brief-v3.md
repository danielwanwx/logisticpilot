## The film's promise

**Five questionable parts should not stop twenty eligible parts.**

Audience: a small parts distributor already using ERPNext, with one operator responsible for receiving exceptions and customer fulfillment. The question is concrete: which stock needs investigation, what can still move, and did the approved work actually reach the ERP?

Product sentence: **LogisticPilot helps small distributors investigate receiving exceptions and keep eligible orders moving.**

Do not open with agent counts, a technology stack, a generic supply-chain dashboard or a list of integrations. Open with the goods and the customer consequence. The primary rehearsal uses a new isolated instance of the 25-part scenario, authorized by the user's subsequent request for a complete rehearsal. The already completed PO25 remains the backup result walkthrough; preserve its current preview and records.

## Before-state and after-state for the primary take

Use one new case with one order for 25 units, two receipt batches, and documented partial-dispatch terms. Names/IDs in this brief are scenario roles; the take manifest must use the provisioner's actual IDs.

- **Before:** A20 has 20 received units and an independently recorded passing inspection. B5 has 5 received units held under inspection policy. Nothing has been dispatched in this new case.
- **Input:** operator selects B5 and uploads the licensed rusted-fastener image. Its lot association is declared POC context. The model supplies the visible corrosion observation and next inspection step.
- **Decision:** ask whether eligible stock can move while B5 stays held. The returned answer must reflect actual order terms and inventory. Ask for a supported preparation only if that action is truly implemented; show a manual fallback as operator work if needed.
- **Human action:** review actual batch, order and quantity on the newly prepared confirmation card; confirm once.
- **After:** ERP readback shows 20 dispatched and 5 still held, with actual native document links. No physical delivery, carrier payment or earned revenue is implied.

The receiving hold may already exist before photo analysis. Say the image adds evidence to the investigation, not that the image caused the original hold. Never insert a failed B5 inspection just to dramatize the photo. A20's photo also does not confer its PASS status.

## What the agent is asked

Use two primary questions and one optional follow-up. Type them live; preserve the full answers in the raw footage.

1. “Why is this batch held, and which order is affected?”
2. “Can the other stock move while this batch stays on hold?”
3. Optional: “What evidence is still needed to release these five parts?”

If showing agent-prepared execution, the rehearsal must establish the actual supported command and a new card. Do not write a script that assumes chat populated a form when an operator filled it manually. For the completed-case backup, replace question 2 with “What has been dispatched, and what still needs attention?” and narrate the recorded execution in past tense.
